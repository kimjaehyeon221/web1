# 배밀기 2000 지원

배밀기 2000은 iPhone에서 배밀기(Dand) 퀘스트와 훈련 기록을 관리하는 앱입니다.

## 자주 묻는 질문

### 기록은 어디에 저장되나요?
기록은 기본적으로 사용자의 iPhone 내부에 저장됩니다. 별도의 회원가입이나 개발자 서버 동기화는 없습니다.

### 앱을 삭제하면 기록도 사라지나요?
네. 앱 삭제 전에 기록 내보내기 기능을 사용해 백업해두는 것을 권장합니다.

### 배밀기 횟수는 자동으로 세나요?
아니요. 사용자가 직접 횟수를 세고 완료 또는 중단을 기록하는 방식입니다.

### 2,000회는 권장 운동량인가요?
아니요. 2,000회는 앱의 상징적인 마지막 Quest이며 의학적 권장량이 아닙니다. 자신의 체력에 맞게 진행하고 통증이나 이상 증상이 있으면 운동을 중단하세요.

### 앱이 카메라나 위치를 사용하나요?
아니요. 배밀기 2000은 카메라, 마이크, 위치 권한을 사용하지 않습니다.

## 문제 해결

앱이 정상적으로 동작하지 않는 경우 다음을 먼저 확인해주세요.

1. 앱을 완전히 종료한 뒤 다시 실행합니다.
2. 최신 TestFlight 또는 App Store 버전인지 확인합니다.
3. 기록이 중요하다면 앱을 삭제하기 전에 먼저 백업을 내보냅니다.
