# PUSH TOTAL 개인정보 처리방침 / Privacy Policy

최종 업데이트: **2026년 9월 1일**

PUSH TOTAL은 계정이나 서버 없이 동작하도록 설계되었습니다.

## 수집하는 데이터

PUSH TOTAL은 개인 데이터를 **수집, 전송, 판매 또는 공유하지 않습니다.** 현재 버전은 이름, 이메일 주소, 전화번호, 정확한 위치, 연락처, 광고 식별자 또는 분석 데이터를 수집하지 않습니다.

## 동작 센서 데이터

사용자가 Pocket Count를 시작하면 PUSH TOTAL은 iPhone의 동작 센서 데이터를 이용해 반복적인 푸쉬업 움직임을 추정합니다. 센서 샘플은 측정 세션 동안 기기에서 실시간으로 처리됩니다. 원본 동작 센서 샘플은 서버로 전송되지 않으며 세션 종료 후 보관하지 않습니다.

## 푸쉬업 기록

확정된 푸쉬업 총합과 개별 세트 기록은 사용자의 iPhone 로컬 저장소에 저장됩니다. 사용자가 앱 안에서 기록을 삭제하거나 전체 기록을 초기화하거나 앱을 제거하기 전까지 기기에 남습니다.

## 제3자 서비스

현재 버전에는 광고, 분석, 사용자 계정, 클라우드 동기화 또는 제3자 데이터 수집 서비스가 포함되어 있지 않습니다.

## 보관 및 삭제

앱 안에서 개별 저장 기록을 삭제하거나 모든 앱 기록을 초기화할 수 있습니다. PUSH TOTAL은 사용자 계정이나 서버 데이터베이스를 운영하지 않으므로 원격에서 삭제해야 할 계정 데이터가 없습니다.

## 권한

동작 및 피트니스 권한은 사용자가 Pocket Count를 선택할 때 요청합니다. 권한을 허용하지 않으면 권한을 다시 허용하기 전까지 Pocket Count를 사용할 수 없습니다. 현재 버전에는 자유 수동 입력 기능이 없습니다.

## 기록 내보내기

사용자가 기록 내보내기를 선택하면 iOS 시스템 공유 시트가 열립니다. PUSH TOTAL은 내보낸 내용을 자동으로 외부 서버에 업로드하지 않으며, 공유 대상은 사용자가 직접 선택합니다.

## 정책 변경

향후 클라우드 동기화, 분석, 광고, 계정 또는 다른 데이터 처리가 추가되면 해당 버전 출시 전에 본 정책과 App Store 개인정보 공개 내용을 함께 갱신합니다.
